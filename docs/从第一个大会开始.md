# 从第一个大会开始

> 30 分钟上手路径。假设你已经装好了 skill（见 README）。

## Step 1 · 给它一个大会

跟你的 agent 说：「下一个大会是 <大会名>，<日期>，<城市>。」

它会走 Phase 0：抓官网，拿回四样东西——联系通道、硬事实（日期/规模）、决策链（谁拍板）、赞助商分级（谁是金主）。

**你要做的**：核对调研结果。规模数字必须按官网复核，不凭印象。

## Step 2 · 定口径（10 分钟，最值钱的一步）

打开 `templates/口径表.md`，9 条逐条填。三条最容易踩的：

- **主身份只报一个**——你是「黑客松获奖者」还是「内容创作者」？选一个，其他全部降级为能力证明。
- **禁用词定 3 个**——凡是你说了会显得底气不足的词（比如「练手」「刚起步」），写进去，定稿前 grep 清零。
- **报价现在就定**——不要等对方问。单日全包一个数，分项一张表。

## Step 3 · 选照片（审美归你）

从你的活动现场照片里挑 15-30 张进 `img-pool/`。AI 不替你选照片——它只会把你选好的图拼进版式。

封面图记得加批注：「封面照片：XX 现场，我在其中」。

## Step 4 · 生成提案 + 验收

Agent 按 8 页骨架生成 HTML → 导出 PDF → **逐页看图**（命令不报错 ≠ 排版没崩）。

你不满意就说哪里不满意，改到满意为止。这一步没有次数上限，有上限的是你的耐心。

## Step 5 · 过目邮件 + 发信清单

邮件只有 4 段。发信清单上只有两个文件：最终版 PDF + 最终版正文。

**然后你自己点发送。** 用你自己的邮箱。这是红线，不是流程建议。

## 换第二个大会

只改三样：大会名、调研数据、口径表。骨架不动。

> 这就是这条管线的全部秘密：**把 admin work 产品化，把审美和发送键留给人。**
